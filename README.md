# REAPER TACTICAL COMMUNITY 🪖

Veřejný, responzivní web airsoftového týmu. Jazykové varianty CZ/EN.

## Web
https://kvaltik.github.io/Reaper-Tactical-Community/

## Aktuální stav
- Funkční statická úvodní stránka a navigace
- Sekce: O nás, Tým a nábor, Akce, Výstroj, Galerie, Komunita, Bezpečnost, Kontakt
- CZ/EN přepínač, mobilní menu, načítací animace
- Registrace, profily, fórum, Mission Creator, Team Builder, Loadout Builder, Command Center, oznámení a administrace: **zatím nejsou aktivní**

## Publikování
1. GitHub: Settings → Pages
2. Source: Deploy from a branch
3. Branch: main, folder: /(root)
4. Save
5. Po publikaci otevřít uvedenou URL.

## Bezpečnost
Nedávejte hesla, admin API klíče nebo service-role klíče do repozitáře. Pro účty je plánován samostatný backend s ověřováním a databázovým RLS. Veřejná statická verze neshromažďuje osobní údaje.

## Rozvoj
1. Oficiální logo, fotky se souhlasem členů a kontakty
2. Supabase Auth, DB a role admina
3. Akce, nábor, hráčské profily
4. Fórum, galerie, zprávy, výstroj, dashboard
